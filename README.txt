SAN — PERSONAL UNIVERSE
=======================

ISI FOLDER
- index.html : konten website
- style.css  : desain, responsif HP/laptop, dan animasi logo
- script.js  : menu HP, tahun otomatis, kontrol musik

CARA MENJALANKAN DI WINDOWS
1. Ekstrak ZIP ini ke folder yang mudah ditemukan.
2. Buka folder san_personal_website.
3. Klik dua kali index.html. Website akan terbuka di browser.
   Untuk pengembangan sederhana, ini sudah cukup; tidak perlu instal aplikasi.

CARA PERSONALISASI
1. Buka index.html menggunakan Notepad atau editor teks.
2. Cari teks "SAN" atau paragraf contoh dan ubah sesuai kebutuhan.
3. Ganti tautan sosial https://www.instagram.com/, tiktok, youtube, dan Discord
   dengan URL profil akunmu sendiri.
4. Cari emailkamu@example.com lalu ganti dengan email yang ingin ditampilkan.
5. Simpan perubahan dan refresh browser.

MUSIK LATAR
- Siapkan file audio MP3 yang kamu punya hak untuk menggunakannya.
- Letakkan di folder yang sama dengan index.html.
- Ubah nama file menjadi music.mp3.
- Klik tombol MUSIC di pojok kanan bawah untuk memutar atau menjeda.
- Browser biasanya mewajibkan pengguna menekan tombol terlebih dahulu sebelum audio diputar.

GALERI KARYA
- Tiga kartu di website adalah contoh visual CSS, bukan unggahan karya asli.
- Untuk sekarang, edit judul dan deskripsi langsung di index.html.
- Untuk memasukkan gambar karya asli, taruh file gambar di folder website dan tambahkan
  elemen <img src="nama-gambar.jpg" alt="Deskripsi karya"> di kartu yang sesuai.

CARA PUBLIKASI GRATIS DENGAN GITHUB PAGES
1. Buat akun di https://github.com/ jika belum punya.
2. Buat repository baru, misalnya san-personal-website.
3. Unggah index.html, style.css, script.js, dan music.mp3 (jika dipakai).
4. Buka Settings > Pages di repository.
5. Pada bagian Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder / (root), lalu Save.
7. Tunggu proses publikasi selesai. URL biasanya berbentuk:
   https://USERNAME.github.io/san-personal-website/
   Ganti USERNAME dengan nama akun GitHub kamu.

CATATAN
- Hosting GitHub Pages gratis untuk website statis seperti ini.
- Jangan unggah password, alamat rumah, atau informasi pribadi sensitif.
- Musik, video, dan gambar harus milikmu atau punya izin untuk digunakan.
- Jika nama repository berbeda, URL publiknya juga akan berbeda.
